# Emika Sandina - Personal Portfolio

A sleek, responsive personal portfolio website built to showcase my experience across full-stack development and machine learning. As a Computer Science undergraduate passionate about building practical, user-focused software, I created this space to highlight my technical journey, core skills, and featured projects like DengueGuard and my credit risk prediction model.

**Live Demo:** https://emika-sandina-dev.vercel.app/

## 🚀 Features

* **Modern, Container-Based UI:** Designed with a clean, professional layout inspired by modern developer portfolios.
* **Light & Dark Mode:** Fully functional theme toggling with carefully selected color palettes for optimal contrast and readability.
* **Responsive Design:** Seamless experience across desktop, tablet, and mobile devices.
* **Project Showcase:** Detailed breakdowns of my work, including React front-ends, REST API integrations, and predictive machine learning models
* **Dedicated Skills Section:** Categorized technical proficiencies spanning web development and data science.
